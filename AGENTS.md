# Agent Instructions — demo-prompter

## Overview

Browser-based teleprompter for remote demos and presentations. Single self-contained HTML file — no build step, no dependencies.

## Usage

1. Open `index.html` in any browser
2. Paste markdown script or upload `.md` file
3. Adjust speed/size, click **Start**

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Pause / resume |
| `↑` `↓` | Adjust scroll speed |
| `←` `→` | Jump backward / forward |
| `Home` | Back to top + reset timer |
| `Esc` | Return to edit mode |

## Rules

- Keep it single-file — no external dependencies.
- Markdown support: headings, bullets, bold, italic, inline code, blockquotes.
- Host anywhere: local file, GitHub Pages, static CDN.
